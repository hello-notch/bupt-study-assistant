## 1. 第二课堂数据源实测

- 当前只读接口能够鉴权并返回 HTTP 200，但测试时活动列表为空。
- 已验证过期 Bearer token 可通过官方网站登录页自动续签；网页验证拒绝默认自动化标记时使用项目 Chromium 的兼容启动参数。
- 需要在确实存在可报名活动时，对照微信小程序验证活动名称、时间、校区、类别、地点和报名区间。
- 如果当前接口不是学生端活动列表，应重新从已登录页面的网络请求中确认只读 GET 接口。
- 无论接口如何调整，都不得实现或调用报名、签到、退选接口。
