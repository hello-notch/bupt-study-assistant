## 第二课堂排查

- 原构建直登接口返回 420，回退网页后读取到过期 JWT；列表连续两次使用同一个过期
  令牌并返回 401。Android 站点存储清理未能阻止旧令牌立即复用。
- 改为在可信第二课堂页面内同步移除过期或被拒绝的令牌，并重新加载页面内会话；
  不为此清除全部校园 Cookie 或其他来源的存储。
- 随后的网页登录实测收到官方 420 错误，内容为验证码错误。官方页面将验证放在
  `/captsec` iframe 内，原应用隐藏该窗口，用户无法完成验证。
- 最新实现提交登录后显示官方窗口，等待用户完成验证码，并移除失败后的盲目重试；
  不自动解题、不伪造验证结果、不绕过官方验证。
- 最新实现 41 项单元测试、类型检查和 Debug/Release 构建通过。手机重连后覆盖安装，
  确认官方验证码 iframe 已显示；验证完成后活动列表和详情均在线读取成功，
  无需伪造令牌或验证码结果。第二课堂问题已通过该 Debug 构建的真机复验。
