# 邮学伴桌面版内测后续事项

本文记录 0.1.0 Windows 免安装内测包完成后仍需处理的工作。当前版本已经可以启动 Electron 客户端、隐藏原生菜单栏，并连接开发者电脑上的服务端，但仍属于受控内测版本，不应直接作为公开生产服务发布。

## 当前内测基线

- Windows x64 免安装目录由 `client/` 中的 Electron Builder 配置生成；执行 `pnpm run dist:win` 后，产物位于 `client/dist/win-unpacked/`。
- 客户端当前连接 `http://[2001:da8:215:8f02:7f5b:8f99:8107:90c3]:8787`。
- `run-server.cmd` 使用 Vite 开发服务器监听 IPv6，复用 `web/dev-api.ts` 提供认证、AI、教务、校园和电费代理。
- 客户端已经禁用 Electron 原生应用菜单；前端类型检查、Vite 构建、目录打包和真实 Windows 启动均已通过。
- 当前程序未设置正式应用图标、未做代码签名，也没有自动更新能力。

## P0：扩大跨网内测前必须完成

1. **使用域名和 HTTPS**
   - 为稳定域名配置 AAAA 记录，不继续把可能变化的校园网 IPv6 写死在客户端。
   - 使用受信任证书，只对外开放 HTTPS 端口；账号密码、会话和 AI 请求不得继续通过明文 HTTP 传输。
   - 客户端改为读取单一发布环境配置，并重新构建内测包。

2. **部署正式服务端进程**
   - 将 `web/dev-api.ts` 从 Vite 开发中间件拆成可独立部署、可重启和可监控的正式 HTTP 服务。
   - 使用反向代理或服务管理器处理 TLS、启动恢复、日志轮转、健康检查、请求体上限和超时。
   - 不把 `server/index.mjs` 中尚未接入完整校园能力的原型误作生产入口。

3. **完成认证与滥用防护**
   - 会话不能只保存在进程内存；Refresh Token 只保存哈希，支持撤销、过期和服务重启恢复。
   - 使用 `Secure`、`HttpOnly` Cookie 或等效安全方案，并增加登录、注册和模型接口限流。
   - 内测阶段使用邀请码或白名单限制开放注册，避免公开 IPv6 被扫描后消耗模型额度。

4. **验证公网 IPv6 可达性**
   - 从与服务端不同的 IPv6 网络实测登录、普通 API、流式 AI 回复和大图片请求。
   - 核对 Windows 防火墙、校园网入站策略与 IPv6 前缀变化；不得把本机代理虚拟网卡地址当作公网地址。
   - 准备无 IPv6 网络的访问方案，通常由域名同时提供 IPv4，或使用可信的双栈反向代理。

5. **隔离用户与开发者凭据**
   - 明确哪些信息门户、教务和第二课堂数据可以作为公共缓存共享。
   - 个人课表、成绩、报名记录等不得使用开发者个人校园会话代查；没有合法稳定授权方式时暂不开放。
   - 复核隐私说明、数据保存位置、模型转发范围和删除策略与真实实现一致。

## P1：正式公开发布前完成

- 设计并配置 `.ico` 应用图标、公司/作者信息、文件版本和版权元数据。
- 购买或配置 Windows 代码签名证书，减少 SmartScreen 的“未知发布者”提示。
- 增加自动更新、版本回滚和发布渠道；更新包必须校验签名和哈希。
- 将任务、课程、对话等大数据从 `localStorage` 逐步迁移到 IndexedDB 或 SQLite，并实现导出、备份和迁移。
- 增加服务端数据库备份、恢复演练、结构化脱敏日志、错误追踪、额度统计和告警。
- 为桌面端补充离线页、连接诊断、服务端地址不可达提示与版本不兼容提示。
- 对安装目录版和压缩包执行恶意软件扫描，并在发布页提供 SHA-256。

## 每次内测发版检查

1. 确认发布 URL、证书、DNS 和服务端健康状态。
2. 扫描 Git 暂存区和打包文件，确保不含 `.env`、API Key、Cookie、密码、数据库、日志或校园缓存。
3. 运行前端 TypeScript 检查、Vite 构建和相关 Python 回归测试。
4. 在真实 Windows 客户端验证登录、退出、自动登录、AI 流式回复、校园错误态、外链和菜单栏隐藏。
5. 从外部网络验证 IPv4/IPv6 可达性，并确认服务端重启后账号与会话行为符合预期。
6. 压缩整个 `win-unpacked` 目录，校验压缩包完整性，记录版本号和 SHA-256 后再发送给测试用户。
