# Android 课表与教学云作业

## 课表

- 移动布局只依据当前选择的周计算可见列、占用节次与末节；没有周末课时显示周一至周五，有周末课时保留七列。
- 内部空节次使用紧凑行，最后一门课之后不再显示空行。节次上限仍为 14，跨节课程依旧使用一个跨行块。
- 课表占据页面剩余高度，为底部导航预留空间。课程完整信息仍可点开详情查看；添加按钮可以添加隐藏的日期和节次。
- 桌面宽度保留七列、十四节布局。

## 同步契约

`POST /api/homework/sync` 的请求体可以包含 `interactive: true`，表示允许显示学校统一认证窗口。自动刷新使用非交互模式。

成功响应必须包含 `complete: true`、`accountKey`、`updatedAt` 和 `items`。UI 只接受当前绑定账号的完整快照。`accountKey` 是设备内运行时对账号生成的摘要，不是登录凭据。密码、Cookie 和令牌不会传给 UI。

教学云官方页面在 2026-09-18 使用以下只读接口：

| 内容 | 接口与字段 |
| --- | --- |
| 学生待办 | `GET /ykt-site/site/student/undone?userId=...`，`data.undoneList`；首页在客户端分页，不截取首页六条 |
| 作业识别 | `type=3`，`activityId`、`activityName`、`siteId`、`endTime` |
| 作业详情 | `GET /ykt-site/work/detail?assignmentId=...`，`assignmentTitle`、`assignmentContent`、`assignmentEndTime` |
| 课程名补全 | `GET /ykt-site/site/detail?id=...`，`siteName` |

接口域为 `apiucloud.bupt.edu.cn`；页面源为 `ucloud.bupt.edu.cn`。当前登录 Cookie 带 `iClass-` 前缀；仅在教学云源内读取必要的认证字段，HTTP 请求由设备内运行时发起。CAS 回调卡住时允许一次重新打开首页；API 明确返回鉴权失效时，交互同步可重新认证一次。网络读取与取消信号关联，不会因为界面取消而继续进行整批详情请求。

不把论坛、调查、测验与作业互评作为作业导入。不请求作业提交、发布、删除或批改接口。

## 本机任务规则

- 标题为 `[作业][课程名]作业标题`；正文在详情弹窗中经白名单清理后展示，保留段落、表格、图片与安全链接。
- 无时区的学校截止时间按 UTC+08:00 解释；缺少截止时间时显示“未设置截止时间”，不编造日期。
- 自定义任务始终排在教学云作业之前，各组内按截止时间排列。
- 只有完整成功快照才执行对账：仍出现的作业为 `todo`，此前存在而本次消失的作业为 `submitted`。
- “已提交”是按用户要求对待办消失作出的本机状态归类，不是本应用执行提交，也不是查询提交凭据后的证明。
- 网络失败、登录失败、未知结构、数量不一致或任一详情失败，均不做对账，不把旧作业误标为已提交。
- 待交作业无法手动修改状态、修改正文或删除；已提交作业可以删除。AI 助手工具受相同限制。
- 删除已提交记录后，空快照不会重新生成它；如果平台重新把它列为待交，允许恢复为新的待交记录。
- 按账号隔离作业；不同绑定账号的结果不互相更新。持久化 key 升为 `youxueban-state-v10`，保留 v9 等旧数据迁移。
- “查看作业”清空搜索词，选择全部状态并应用课程名筛选。名称比较统一全半角、空白和教务末尾的 `#`、`○`、`◇` 标记，不使用任意子串匹配。

## 验证边界

自动化测试覆盖完整空结果、超过首页数量的列表、标题与正文映射、时区、鉴权/网络/业务错误、部分详情失败、取消、账号隔离、状态迁移、只读限制、删除与再次出现、存储迁移和 HTML 注入清理。

隔离页面测试覆盖 320、390、720 像素宽度的工作日、周末与空周，以及桌面布局不变；通过截图与布局边界检查验证一屏课表。

真机已验证统一认证、成功同步空待办和现有真实课表的一屏显示。当前平台没有作业，因此真实非空作业详情和“实际提交后自动变化”尚未进行端到端实测；这些路径目前由官方前端接口契约和隔离测试覆盖。测试 APK 为 Debug 构建，不能当作正式签名发布包。
