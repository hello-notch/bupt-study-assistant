# 邮学伴本地优先架构

## 目标

邮学伴不提供自建用户体系，也不依赖开发者部署的业务服务端。Windows EXE 加载安装包内的 Vue 页面；需要联网的校园和 AI 能力由当前设备直接访问用户指定或学校官方系统。

## 分层

```text
Vue 页面
  │  apiFetch（统一 API 形状，不持有敏感值）
  ├─ Windows preload IPC ── Electron local-runtime.cjs
  └─ 浏览器开发态 ── Vite dev-api.ts（仅本机调试）
```

渲染页面只接收配置状态、脱敏账号、API URL、模型名和业务结果。密码、API Key、Cookie 与 token 不进入 `localStorage`、页面状态或控制台。

## 本机数据

- 普通数据：昵称、头像、任务、课程、宿舍号、已读状态、对话和偏好使用 `localStorage`。
- Windows 敏感数据：Electron `safeStorage` 加密文件；信息门户统一认证由运行时发现或按需下载的隔离 Playwright Chromium 完成，会话 Cookie 加密写回本机配置，业务请求仍由本机运行时直连。
- 删除校园配置时同时清除账号密码及校园会话；删除模型配置时清除 API Key 和模型选择（API URL 为固定值，不单独保存）。

## 首次使用

1. 欢迎页只输入昵称，背景圆球按秒运动、碰撞并变色。
2. 进入主页后提示分别绑定统一身份认证与教务系统账号，说明本机保存与删除方式。
3. 教务账号验证成功后读取个人课表，显示导入预览并询问替换或合并。
4. 用户可稍后绑定；本地任务、文件课表等功能不受影响。

## 校园数据

- 教务：保存账号后不自动读取课表；课程页可按需读取当前学生个人课表，或从 XLS/XLSX/CSV 文件导入。
- 信息门户：读取通知列表与门户首页“待办中心”；待办中心条目优先进入“今天”，所有条目保留具体 URL。
- 第二课堂：只读活动查询。成功空数组表示当前无活动，不视为失败。
- 电费：仍需用户输入楼宇和宿舍号；设备登录官方电费页面后查询对应楼、层和房间。
- HTTP 成功不等于业务成功；必须识别登录页、验证码、系统提示页、无效 JSON 和页面结构变化。

## 学习助手

- 首次进入助手且未配置时，要求填写 DeepSeek API Key；未配置前不发送请求。
- API 地址固定为 `https://api.deepseek.com`，设备内运行时固定提供三个当前受支持模型并允许切换，不依赖 `/models` 探测。
- 聊天使用 DeepSeek 的 `/chat/completions`，保留课程、DDL、校园和电费工具调用。
- 只有视觉模型允许 PNG/JPEG/WebP 图片；单张和单消息数量均受限制，不持久化模型推理过程。

## 失败与平台差异

在线、成功空结果、鉴权失败、验证码、网络失败和解析失败必须明确区分，不得返回演示数据。Windows 客户端支持本机校园运行时。
