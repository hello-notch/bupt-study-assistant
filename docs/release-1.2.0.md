# 邮学伴 1.2.0

本次仅发布 Android APK。桌面端尚未完成本次更新的适配，不发布 Windows 1.2.0；
已有 Windows 1.1.0 发布包保持不变。

## 更新内容

- **Android 客户端**：提供设备内校园认证、课表导入、电费查询、校园通知、第二课堂和
  学习助手；敏感配置通过 Android Keystore 保护，不需要部署邮学伴服务端。
- **教学云作业同步**：读取课程、作业标题、正文和截止时间，支持手动同步与前台自动
  刷新；课程详情可直接查看对应作业。同步失败或不完整时保留已有记录，不误改状态。
- **作业状态管理**：自定义任务优先显示，待交作业不可手动完成或删除；此前同步过的
  作业在完整待办列表中消失后标记为“已提交”，已提交记录可删除。此标记不代表应用
  执行了提交，也不构成学校平台的提交凭证。
- **手机课表优化**：按当前周隐藏无课周末、压缩空节次、裁掉末节之后的空行；
  空周保留完整十四节，优化换周、添加和导入操作布局。
- **系统提醒**：任务与课程提醒交由原生持久化闹钟队列处理，增加通知及准时提醒权限
  检查、静音时段处理和恢复机制，减少前台重复通知。
- **返回与主题**：系统返回键和手势优先退出编辑、详情及弹窗，系统栏随浅色或深色
  主题切换；优化软键盘弹出时的聊天输入区。
- **图片问答**：受支持的 Flash 模型可发送 PNG、JPEG、WebP 图片；增加压缩、预览、
  数量与大小校验，修复长输入和附件遮挡发送按钮的问题。
- **电费认证修复**：统一认证会话过期而门户 Cookie 仍有效时，强制进入统一认证续期，
  避免重复打开门户却仍无法查询电费。
- **第二课堂登录修复**：不再复用过期或被服务器拒绝的令牌；需要验证码时显示官方
  登录窗口供用户完成，不再隐藏等待或盲目重复登录，也不清除其他校园系统会话。

## 安装与注意事项

- APK：`YouXueBan-1.2.0-Android.apk`，版本 `1.2.0` / `12000`，支持 Android 11 及以上。
- 本次使用独立 Release 签名，关闭应用及 WebView 调试，不是 Debug 测试包。
- **旧 Debug 测试版不能直接覆盖安装**。请先保留重要数据，再手动卸载测试版并安装；
  卸载会删除本机数据。后续正式版使用相同签名时可覆盖升级。
- 教学云需要校内网及有效统一认证，只同步作业待办，不回溯全部历史作业，不代替提交。
- 准时提醒需开启通知、闹钟与提醒权限，并允许后台运行；系统省电或强行停止可能影响送达。
- 图片附件不等于通用文档支持，本版不提供 PDF/Word 上传。
- 第二课堂仍只提供查询、查看和订阅，不提供报名、签到或退选。
- 第二课堂会话失效时可能需要在应用打开的官方窗口中手动完成验证码。

- 真实非空作业、实际提交后的状态变化、设备重启和长时间深度休眠仍待进一步真机验证。
