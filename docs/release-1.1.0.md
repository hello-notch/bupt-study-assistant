# 邮学伴 1.1.0 发布说明

## 主要更新

- 桌面端继续采用本地优先架构，移除已退役的网页服务端、旧机器人入口和重复启动脚本。
- 增强课表导入：支持 XLS、XLSX 和 CSV，导入前可预览并选择课程；按课程名、星期、起止节次、周次、教师和地点识别安排，分周授课不会被错误合并，重复导入不会产生副本。
- 更新校园信息页：通知、第二课堂活动和信息门户待办中心统一展示，待办优先进入“今天”，并保留原始链接。
- 增强本地缓存：信息门户和第二课堂成功读取的数据会缓存到设备；刷新失败时继续展示最近一次真实数据并标注缓存来源。
- 完善登录、凭据和模型配置体验：校园统一身份认证、教务系统和 DeepSeek 配置均可在设置中修改或删除；敏感信息由 Electron `safeStorage` 加密保存。
- 调整认证运行时：优先使用 Playwright 缓存或本机 Chrome/Edge，确实缺少 Chromium 时才下载，发布包不携带 Chromium、headless shell、ffmpeg 和构建缓存。
- 新增本地运行时与课表导入回归测试，覆盖分周课程保留和重复导入规则。

## 兼容与注意事项

- Windows 发布包为完整目录压缩包，解压后直接运行 `邮学伴.exe`，不需要另装 Node.js。
- 本版本不自动迁移测试版的应用用户目录；首次启动可能需要重新填写昵称并绑定校园账号。
- 由于课表识别规则修复，旧版本已经遗漏的课程需要重新导入原课表文件。
- 第二课堂仍只支持查询、查看和订阅，不支持报名、签到或退选。
